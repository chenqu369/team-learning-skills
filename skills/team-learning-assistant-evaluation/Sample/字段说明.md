# 助教评价样例说明

本目录只提供匿名结构，不提供当期人员、等级、日期、金额或平台默认值。先读 [SKILL.md](../SKILL.md)，字段及业务规则统一查 [Rules.md](../Rules.md)，本文件不另维护规则。

| 文件 | 类别 | 怎么使用 |
| --- | --- | --- |
| [配置.json](配置.json) | 示例输入 | 连接共享表快照与人工确认；可运行本地 evaluation-preview。日期和连接程序为空，不可用于真实发证 |
| [共享表快照.json](共享表快照.json) | 示例输入 | 展示 headers＋rows；真实运行换成当期完整共享表读取 |
| [评价奖励确认.json](评价奖励确认.json) | 示例输入 | 展示以业务身份键为顶层键的 eligible、s_bonus、states；不覆盖身份和等级 |

| 要查什么 | 权威位置 |
| --- | --- |
| 配置、来源与决策字段 | [Rules S1](../Rules.md#s1-读取当期清单) |
| 开营／结营职责码与状态 | [Rules S2](../Rules.md#s2-核对开营职责)、[S4](../Rules.md#s4-核对结营职责) |
| 等级、证书日期、鲸币 | [Rules S5](../Rules.md#s5-确认人工评价)、[S9](../Rules.md#s9-处理证书决定)、[S11](../Rules.md#s11-核对并处理鲸币) |
| 平台连接程序与写后回读 | [Rules S7](../Rules.md#s7-回读平台身份与来源) |

样例运行只会生成本地预览。真实运行保留 sample_only 边界，不把样例日期、人物或已核实状态复制为当期事实。
