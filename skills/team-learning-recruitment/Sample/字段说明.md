# 招募 Sample 索引

本目录主要保存格式示例，不维护第二套业务规则。课程、项目、报名人员和日期均为匿名模拟值；例外是[负责人微信二维码.jpg](负责人微信二维码.jpg)：用户已确认它是未提供本期新二维码时使用的默认业务图片。[负责人微信示例.json](负责人微信示例.json) 记录图片中的展示名，不能把它当成已核实的文字微信号。业务规则统一见 [../Rules.md](../Rules.md)；操作命令与完成依据见 [../SKILL.md](../SKILL.md)。

| 文件 | 用途 | 边界 |
| --- | --- | --- |
| [课程规划标准.md](课程规划标准.md)、[课程信息.json](课程信息.json) | 对照课程规划填写 JSON 的匿名示例 | 模拟课程、Task、群数与日期；不得当作本期事实 |
| [配置.json](配置.json) | 展示入口配置与相对路径写法 | 配置内相对路径按配置文件目录解析；示例 ID/路径不可用于生产 |
| [上期招募配置快照.json](上期招募配置快照.json) | 展示脚本读取上期证书配置和两类岗位提示语所需的最小结构 | 固定匿名 Sample；其中的 ID、证书值和文案不能继承到本期。实际继承须重新读取真实上期项目 |
| [新建项目.json](新建项目.json) | 展示项目创建字段与创建后独立配置 | `null` 表示待确认；本文件不是线上创建证明 |
| [贡献者招募项目.json](贡献者招募项目.json) | 展示岗位草稿的本期覆盖配置 | `target_project_id` 必须替换为本期回读的真实 ID |
| [负责人微信示例.json](负责人微信示例.json)、[负责人微信二维码.jpg](负责人微信二维码.jpg) | 保存默认微信联系入口图片及可见展示名 | 未提供新二维码时使用这张真实图片；新图优先。`owner_wechat` 仍为 `null`；平台 URL 需上传后核对，不能填本地路径 |
| [助教课程事实.json](助教课程事实.json) | 展示脚本派生的兼容格式 | 新流程直接输入 `课程信息.json`，无需手工维护此文件 |
| [项目任务JSON.json](项目任务JSON.json) | 展示完整项目任务快照结构 | 只用于本地进度试跑，不代表实时平台状态 |
| [月度助教清单.json](月度助教清单.json) | 展示共享清单值与合并范围结构 | 人员和人工字段均为匿名示例，不得写入生产 |

课程输入匿名样例为[课程信息.json](课程信息.json)和[课程规划标准.md](课程规划标准.md)，均不能代替当期规划。业务规则只在招募 [Rules.md](../Rules.md) 维护。
