# 打卡与结营样例说明

匿名样例只用于理解结构。使用顺序为 [SKILL.md](../SKILL.md) → [Rules.md](../Rules.md) → 本目录，不在这里重复维护业务规则。

| 文件 | 类别 | 怎么使用 |
| --- | --- | --- |
| [打卡核验输入.json](打卡核验输入.json) | 示例输入 | 可用于本地 graduate 演示；course_info 是对象，records 是数组。示例课程、Task、日期、人员不可用于当期 |
| [课程日历输入.json](课程日历输入.json) | 示例输入 | 演示03:00、24:00、待确认节点和起止日期；由 course-calendar.mjs 生成本地计划，不写 Base |
| [组队学习打卡Base.json](组队学习打卡Base.json) | 结构参考 | 展示原始表、结营名单与领取视图。参考标题含历史月份，live_schema_verified=false，真实 schema／ID／权限须重读 |

| 要查什么 | 权威位置 |
| --- | --- |
| 原始字段、必需项与选项 | [Rules S2](../Rules.md#s2-比较表单字段与选项) |
| 日历字段、日期与批量操作 | [日历操作说明](../references/课程日历操作.md)、[Rules S4A](../Rules.md#s4a-课程-task-日历) |
| 核验输入／输出与 registry 保存 | [Rules S5](../Rules.md#s5-完整读取原始提交) |
| 身份、Task、昵称和人工例外 | [Rules S6](../Rules.md#s6-核对稳定身份)、[S7](../Rules.md#s7-核验全部必需-task) |
| awards 输入与人工优秀保留 | [Rules S8](../Rules.md#s8-记录人工优秀选择) |

样例不会自动配置线上表单、创建 Base、写回名单或制作正式证书。
