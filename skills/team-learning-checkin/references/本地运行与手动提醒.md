# 跨 Agent 复用：本地运行与手动提醒

任何能运行Node.js和lark-cli的Agent均可使用同一个正式发布包，不依赖Codex对话或特定模型。分享完整的 `team-learning-skills/` 发布包，保留内部结构；真实人员快照、身份登记、编号账本和授权按项目单独管理，不把业务数据写进Skill正文。

## 接手顺序

1. 先读目标项目的AGENTS.md，定位正式Skill包、项目根目录和当期课程JSON。不可套用本机D盘路径、10月课程或历史Base ID。
2. 检查Node.js ≥20、lark-cli路径及目标用户授权；读取当期JSON、独立人工确认、身份登记、课程编号登记、别名与正式账本。首次必要缺口立即列明。
3. 根据下面字段配置本地入口，在Skill包根目录运行预览；预览不修改飞书。检查每条原始记录的去向、身份异常、人工名单课程与拟变更字段。
4. 已获本次授权时运行apply；运行器再次读取来源，发生变化则停止重算。只更新系统字段，保存回执并全量回读；不把待确认对象记作全部完成。
5. 交接结果目录、来源版本、写入与复用数量、人工字段变化及待办。失败后重新运行读取线上现状，不能重放旧批次。

```text
node runtime/learner/local/run.mjs --config "<目标项目的配置JSON>" --preview
node runtime/learner/local/run.mjs --config "<目标项目的配置JSON>" --apply
```

## 配置合同

若另获终版及领取名单自动同步授权，按 [名单准备与周期同步](../../team-learning-certificates/references/名单准备与周期同步.md) 使用 `publish-run.mjs`；配置增加 `final_table` 和 `receipt_table`。项目月份登记负责当前月路由，缺该月配置停止；原始打卡同步、名单发布、手动提醒分别记录运行结果。

`workspace_root` 相对配置文件目录；其他文件路径相对该项目根目录。Base与表ID必须来自本期真实入口，不从样例猜测。配置不得包含密码或令牌。

| 字段 | 含义 |
| --- | --- |
| workspace_root | 项目根目录 |
| base_token / source_table / roster_table | 本期Base、原始打卡表、结营与评优表 |
| course_info | 当期课程JSON，后续规则唯一入口 |
| confirmations | 人工别名、跨群确认及人工核准结营名单；每项有依据 |
| identity_registry | 本期稳定身份状态，续跑复用，不清空 |
| course_codes / course_aliases / certificate_ledger | 跨期统一课程编号、别名及正式账本；不同课程不能重号 |
| output_directory / state_directory | 每批快照、日志、回执及运行锁/最新状态目录 |
| cli（可选） | CLI实际可执行路径；默认Windows PATH中的lark-cli.exe |

跨设备须单独准备真实输入和登录；CMD只是Windows双击包装，其他Agent可直接运行上述Node命令。平台权限和接口限制仍适用。

## 保留与恢复

- 既有人工昵称、优秀标记、评阅人、依据、备注不更新；原始打卡不改、不删除名单。
- 空人员标识按原始来源分别处理，不能合为一人。人工名单课程跳过飞书结营条件，保留全部制证参数，等待人工核准人员，不生成虚构记录。
- 读取的瞬时网络错误最多重试两次；写入响应不明不自动重试。首次写请求前保存稳定身份，下次重读已成功记录后只补剩余差异。
- `verified`只表示系统字段回读核验；`scope_fully_resolved=false`表示仍有待确认，不能声称全员结营通过。该入口不制作证书。

## 手动提醒与自动同步分开授权

提醒只提示负责人手动双击CMD；不启动CMD，不运行Node同步，不调用飞书。用户选择手动运行时，不能顺带创建自动同步任务。

设置提醒前确认频率、时间及目标时区。优先使用当前可用的提醒工具；无此工具时，Windows可使用包内 `install-reminder.ps1` 创建本机桌面提醒。非Windows应使用该设备可用的提醒设施，不能照搬Windows命令。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<包根>/runtime/learner/local/install-reminder.ps1" -ProjectRoot "<项目根目录>" -At "12:00"
```

这个安装器仅用于用户已明确确认的“工作日12:00、Asia/Shanghai”提醒；其他时间可用At参数，其他频率或时区须先调整触发器并核对，不静默套用。本机时区不符时停止，不修改系统时区。电脑须开机、当前账户已登录；关机或未登录错过的提醒不补发。Windows任务的动作只允许指向 `remind.ps1`，参数为项目根目录，不得指向start.mjs、run.mjs或CMD。

安装后读取任务的触发器、时区、动作、用户和启用状态，保存回执；未实际到时弹窗不能称弹窗已验收。提醒日志在项目 `workflow/state/local-workflow/reminders.ndjson`。停用提醒用任务计划程序禁用对应任务，或 `Disable-ScheduledTask -TaskName <实际任务名>`；只操作本次创建的提醒任务。

时间和启用状态属于项目配置，不写死为所有项目的默认政策。本项目当前选择见项目AGENTS.md及 `workflow/local/reminder.json`。
