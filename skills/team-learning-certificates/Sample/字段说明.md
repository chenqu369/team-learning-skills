# 制证与领取样例说明

本目录只保留结构示例。阅读顺序为 [SKILL.md](../SKILL.md) → [Rules.md](../Rules.md) → 需要的样例。业务与字段规则统一维护在 Rules，不以本文件另立一套口径。

| 文件 | 类别 | 怎么使用与边界 |
| --- | --- | --- |
| [最终制证标准.json](最终制证标准.json) | 示例输入 | 展示 final-plan 输入；部分参数留空以表达待确认。能解析不等于可正式制作 |
| [学习者领取汇总标准.json](学习者领取汇总标准.json) | 示例输入 | 展示 receipt-plan 的 manifest、people、existing_receipts 关系；没有真实成品文件／哈希，不是可直接通过的正式批次 |
| [领取页面设置.json](领取页面设置.json) | 布局参考 | 展示两列与两层分组；真实表、视图、字段 ID 从当期回读取得 |
| [领取表字段样例.json](领取表字段样例.json) | 字段快照 | 2026-10-20 清理后领取表的 7 个字段；ID、选项及关联目标属于当期快照，复用前按 [Rules S11](../Rules.md#s11-执行并回读上传同步布局) 回读更新 |

| 要查什么 | 权威位置 |
| --- | --- |
| 课程、名单、角色与终版字段 | [Rules S1](../Rules.md#s1-确认来源与当前终版) |
| 昵称、行粒度与差异保护 | [Rules S2](../Rules.md#s2-生成终版计划) |
| 实际导出配置与路径 | [Rules S4](../Rules.md#s4-完整导出当前终版) |
| PPT 模板、账本与导出图片 | [Rules S5](../Rules.md#s5-检查制证输入)、[S6](../Rules.md#s6-正式制作) |
| 领取身份、关联、输入与脚本限制 | [Rules S9](../Rules.md#s9-核对领取身份及关联)、[S10](../Rules.md#s10-生成上传同步预览) |
| 单次上传、token 同步、布局与访问 | [Rules S11](../Rules.md#s11-执行并回读上传同步布局)、[S12](../Rules.md#s12-验收下载与访问) |
| 制证完成后自动标注助教清单、输出回写结果 | [Rules S12A](../Rules.md#s12a-自动标注助教清单并输出结果) |

所有文件均为 sample_only 示例；展示 complete／test_mode=false 不构成生产证据。缺当期参数、实际素材、正式账本或真实文件时，停在计划／待确认。
