# 脚本阶段、入口与精简规则

运行代码统一维护在本包 `runtime/`。业务项目保存当期配置、来源、人工决定、身份和编号状态，不复制一整套引擎到项目 scripts 目录。包内命令从包根目录执行；本机 CMD 和按月路由从目标项目根目录执行，按各模块说明区分。

## 按阶段选择入口

| 阶段 | 正式包脚本 | 作用与边界 |
| --- | --- | --- |
| 整理课程 | shared/course-info.mjs | 校验项目指定的当期课程 JSON，派生 Task、日期、人工名单课程与制证参数；缺项列待确认 |
| 助教招募 | assistant/scripts/招募草稿.mjs、招募项目.mjs、招募进度.mjs、飞书清单同步.mjs | 准备岗位、核对报名、清单回读；规划名单回写按招募 Skill 执行 |
| 助教评价 | assistant/scripts/助教评价入口.mjs、单维表评价.mjs、等级发放.mjs | 按人工评价生成预览，平台办理依赖实际适配程序及独立回读 |
| 打卡与结营 | learner/scripts/checkin.mjs、learning-record-contract.mjs；learner/local/engine.mjs、run.mjs | 前两者处理身份和打卡规则，后两者计算线上差异并增量写入；原始记录和人工字段保留 |
| 终版与领取名单 | learner/local/publication.mjs、publish-run.mjs；assistant/scripts/最终证书名单.mjs | 准备逐证终版与逐人领取关联，完整导出当前核准终版；不生成证书图片 |
| 正式制证 | assistant/scripts/个人证书制作.py；learner/scripts/certificates.py、certificates_ppt.py、certificate-ppt-export.ps1 | 分别承担入口核验、编号与成品管理、PPT任务准备、PowerPoint实际导出；四者配合，不能因文件多而合删 |
| 上传与验收 | assistant/scripts/证书附件上传.mjs、上传传输.mjs | 上传当前终版附件、逐证计时和失败核对；领取同步、查询页发布和实际分发继续按制证 Skill 处理 |
| 全流程核对 | shared/workflow-audit.mjs | 核对独立来源、对象覆盖、变更失效和续跑；不能以旧计划验证自身 |

包内路径均省略共同前缀 `runtime/`。脚本存在不等于整条流程已自动化；预览、写入、制证、上传、可领取与实际分发分别验收。

## 项目包装与历史兼容

- CMD、项目月份路由和 Windows 任务只是包装入口，调用正式包，不复制核心实现。提醒和自动同步分别授权、记录结果；本机提醒时间不作为所有接收项目的默认政策。
- 旧电子表格名单、规划 Task 推导、共享课程参数转换等工具，只有仍在处理相应历史材料时才保留。明确标为历史兼容，不再用于生成后续期数的课程规则，也不能反向覆盖当前课程 JSON。
- 历史批次有特殊版式或导出逻辑时，保留项目适配器并显式指定；例如长文字自动缩小字号可能属于有效差异。同名文件不等于可互换，不能把历史版式变化混入简单去重。
- 本包不依赖某台设备保留的历史脚本。当前项目的兼容脚本清单、原始路径与具体批次依据，由该项目脚本索引维护，不写死在通用 Skill 中。

## 删除或合并之前

1. 核对内容哈希、静态导入、Python路径、CLI命令、审计依赖和当前配置。即使源码完全相同，也先更新调用者，再删除副本。
2. 原始代码、用户手工文档、业务输入与正式账本保留。将待删文件及受改动的调用者完整归档，逐文件核验内容，并记录删除及迁移清单。
3. 有效的旧链可以改引正式包；有差异的适配器先解释差异，不能仅凭同名覆盖。一次性修复工具退出日常目录，历史快照与旧验收回执不批量改写。
4. 相应旧功能已经退役时，可一并归档其失去依赖的旧测试；不得删除仍覆盖身份、编号、人工字段保护或失败恢复的有效检查。
5. 改完检查相对导入和资源，并运行受影响的已有测试。Python测试使用 `-B`，缓存不纳入脚本清单或发布包。真实PowerPoint排版、线上写入和权限验证未经执行则明确未验证。
6. 更新涉及模块的 Skill、主 README 导航、项目索引与发布文件清单；发布包保持完整，历史资料和备份不随通用包公开。
